## About me

I'm a software developer and founder of [Directa](https://directa.mx). I work across systems programming, applied AI, and web development, connecting performance-sensitive components to APIs and interfaces people can use.

My projects explore how systems work beneath the surface: vector indexing, dependency reachability, market microstructure, multimodal signal processing, and geometric collision evaluation. I document architectural decisions, build reproducible demos, and make implementation limits explicit.

## Engineering approach

- Build a working end-to-end slice before expanding scope.
- Keep numerical calculations and validation separate from model-generated explanations.
- Test system boundaries, failure paths, and data integrity.
- Document tradeoffs and the reasoning behind architectural decisions.
- Label synthetic data, offline modes, and unfinished features clearly.
